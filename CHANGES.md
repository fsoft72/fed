# Changes

## 2026-11-11

- Added design spec `docs/superpowers/specs/2026-11-11-fed-editor-design.md` (approved).
- Added implementation plan `docs/superpowers/plans/2026-11-11-fed-editor.md`.
- Added backlog of deferred review findings `docs/superpowers/plans/2026-11-11-fed-backlog.md`.
- Task 1: scaffolded the `fed` crate (all dependencies, rustfmt, release profile) with an empty eframe window showing "fed".
- Task 2: added rope-backed `Buffer` (`src/buffer.rs`) with CRLF handling, atomic save, grouped undo/redo, marks and dirty-line tracking.
- Task 3: added search engine (`src/search.rs`) with literal/regex queries, wrapping `find_next`, `find_all`, line-range `substitute` and `replace_all` (single undo step).
- Task 4: added `src/text_nav.rs` (char classes, word motions, line helpers, bracket matching) and `src/editing.rs` (`Selection`, `EditorState`, `EditCommand`, `apply_command` for non-vim editing).
- Task 5: added `src/config.rs` (lenient TOML `Settings`, `ConfigPaths`, `Session`) and `src/keymap.rs` (`Action`, `KeyChord`, `Keymap` with defaults, conflicts and overrides).
- Task 6: added the custom editor widget (`src/view.rs`: virtualized rendering with `ScrollArea::show_viewport`, gutter, selection, caret, word wrap with cached line heights, keyboard/IME/clipboard/mouse input, `Decorator` and `key_handler` hooks) and `src/tab.rs` (`Tab` with grouped typing undo); the app now opens one tab per CLI path and shows open errors at the bottom. `Buffer::is_modified` now also counts edits in an open undo group.
- Task 7: app shell (`src/app.rs`, `src/app/dialogs.rs`): tab bar (modified marker, close button, middle-click close), keymap-driven shortcuts consumed before the editor (plus fixed `Cmd+Shift+Z` redo alias), `FedApp::dispatch` for every `Action` (find/replace/go-to-line/preview/settings report "not available yet" until their tasks), native open/save-as dialogs via `rfd`, unsaved-changes modals for closing a tab or the window, closing the last tab exits, status bar (`path  line:col  LF/CRLF  [+]`, 5 s transient messages, large-file notice), settings and keymap loaded at startup with warnings in the status bar, `ui_theme` applied, session saved on exit and restored when enabled. The editor widget now keeps requesting focus until it sticks (a click elsewhere in the same frame used to drop it).
- Task 8: find/replace and go-to-line bars (`src/find_bar.rs`): incremental search from the caret with `3 of 12` / `no matches` counter, `Aa` and `.*` toggles, Enter/F3 next and Shift+Enter/Shift+F3 previous, Esc closes and refocuses the editor, replace current and replace all (single undo step, `$1` groups only in regex mode), invalid regex shown in the bar, go-to-line to the first non-blank. Matches are highlighted by `MatchDecorator`, which wraps any inner `Decorator`. Shortcut dispatch now matches the exact pressed chord (`Ctrl+Shift+N` no longer fires `Ctrl+N`) and Undo/Redo/SelectAll are ignored while a text field has focus.
- Task 9: incremental syntect highlighting (`src/highlight.rs`): assets (syntaxes and themes) load on a background thread so the window appears first and colors follow; `HighlightCache` stores parser state per line and re-parses only from the edited line; `HighlightDecorator` sits under `MatchDecorator`, takes the buffer dirty line in `prepare` (exposed as `last_dirty()` for the spell checker) and uses `code_theme_dark` or `code_theme_light` by the current visuals; large files stay plain. `StyledSpan.kind` (`Comment`/`String`/`Other`) is available for spell checking. `Buffer::take_dirty_line` now takes `&self` (the dirty line is a `Cell`).
- Task 10: Italian and English spell check (`src/spell/`): `SpellService` loads (or downloads, 30 s timeout, only when `spell_check` is on) the `it_IT` and `en_US` Hunspell dictionaries from the config dir or system dirs on a background thread, with a personal word list (`personal.dic`); `SpellDecorator` underlines misspelled words in comments and strings (code), prose only (Markdown, via pulldown-cmark ranges cached per buffer revision) or everywhere (Plain Text), never in large files. Right click on a misspelled word opens a popup with up to 8 suggestions (one undo step) and "Add to dictionary"; the status bar shows downloading and failures with a retry button. The span-splitting helper of the find bar is now the shared `view::overlay_format`.
- Task 10 fixes: apostrophe groups ("don't") are checked whole (typographic apostrophe normalized) before falling back to the elision split ("l'albero"); bare URLs and HTML entities are never checked; the checker is published as soon as the first dictionary parses, later languages are added to it.
- Task 11: live Markdown preview (`src/markdown.rs`): `Cmd/Ctrl+Shift+V` or the tab bar "Preview" button toggles a resizable right panel rendered with egui_commonmark (tables, task lists, footnotes, code blocks) that re-reads the text only when the buffer revision changes; relative image paths become `file://` URLs, remote images are replaced by `[alt]` text so nothing is fetched; non-Markdown tabs report "preview is only available for Markdown"; image loaders installed at startup.
- Task 12: vim core (`src/vim/`), pure logic over `Buffer` + `EditorState`: `VimState::handle_key(key, buf, ed, settings) -> Vec<VimEffect>` with Normal, Insert, Visual, VisualLine and CommandLine modes. Motions (`motion.rs`: `h j k l w b e W B E 0 ^ $ gg G {n}G f F t T ; , % { } ' \` n N`, counts, `w`/`b` stop on empty lines), operators `d c y > <` with motions, text objects (`textobj.rs`: `iw aw i" a" i' a' i( a( i{ a{ i[ a[`) and doubled forms, vim's `cw` and exclusive-motion rules, `x X D C s S J r{c} p P u Ctrl+R .`, `/ ? n N * #` (Rust regex, case sensitive), marks `m{a-z}` / `'` / `` ` `` (missing mark reports `E20`), Visual `d x c y > < o v V :` (`:` prefills `'<,'>` and sets marks `<` `>`). Each change and each insert session is one undo step; yanks and deletes fill the unnamed register and emit `SetClipboard`. `:` commands go through a single `run_cmdline` stub (`E492`) that Task 13 replaces. Normal-mode parsing and execution live in `src/vim/normal.rs`, state machine tests in `src/vim/tests.rs`.
- Task 12 fixes: the `:help exclusive` column-0 rule now uses the range start line, so backward motions (`db`, `dB`, `d{`, `dN`) stop at the previous line end or become linewise like vim; the preferred column resets after every command except `j`/`k`/arrows and `$` (also after Visual operators and Insert-mode typing/Left/Right); Esc (and a second Enter) drops untouched auto-indent left by `o`/`O`/`cc`/Enter; Normal-mode Enter moves to the first non-blank of the next line (`+`); `:` with an empty line does nothing; motions never target the empty line after a final line break (vim model: `G` on "a\nb\n" lands on "b"), but an edit such as `o<Esc>` may leave the caret there and Normal-mode clamping keeps it until the next motion.
- Task 13: vim command line and UI integration. `src/vim/cmdline.rs` parses and runs `:w`, `:w {file}` (writes a copy), `:q`, `:q!`, `:wq`, `:x`, `:e {file}` (relative to the current file's directory), `:{n}`, `:$`, `:'a` and `:[range]s/pat/rep/[g][i]` with `%`, `n`, `.`, `$`, `'a`, `'<`, `'>` addresses, any delimiter, `\{delim}` escapes and an optional final delimiter (Rust regex, one undo step, `N substitutions` / `pattern not found: p` / invalid regex errors, `backwards range`). `VimState` remembers the last Visual lines for `'<` `'>`, its Insert undo group can be closed from outside (`end_insert_group`, used by `Tab::end_typing` before saves, tab switches and external edits) and reopens on the next typed key. `Tab` gains `vim`. With `vim_mode` on, every editor key goes to vim (`view::egui_event_to_vim_keys`), pastes type text only in Insert mode, app shortcuts fire only with Ctrl/Cmd and never Undo/Redo/Select all, mouse drags enter Visual mode and clicks clamp the caret in Normal mode. A monospace command bar above the status bar shows the command line with a block cursor, or the last message/error until the next key; the status bar shows `-- NORMAL --`, `-- INSERT --`, `-- VISUAL --`, `-- VISUAL LINE --` plus pending keys; the caret is a block outside Insert mode and the Visual selection is drawn inclusively. `:q` on a modified buffer reports `No write since last change (add ! to override)`; toggling `vim_mode` at runtime resets every tab's vim state.
- Task 13 fixes: holding a click past a line end no longer enters vim Visual mode (a drag starts only once the pointer leaves the press position); `:w {file}` refuses an existing other file with `E13: File exists (add ! to override)` and `:w! {file}` forces it (`:w!` alone is `:w`); `:x` writes only a modified buffer before closing; `:w`/`:wq` report the actual save result (nothing when Save As is cancelled); a vim effect that may close or switch tabs (`:q`, `:wq`, `:x`, `:e`) drops the rest of that frame's keys and effects.
- Task 14: settings window (`src/settings_ui.rs`, `Ctrl/Cmd+,` toggles it, Escape or the X closes it): Editor (font family combo with filter and "monospace only", font size 6..72, tab width 1..16, insert spaces, line numbers, word wrap), Appearance (System/Light/Dark, light and dark code themes once the syntax assets are loaded), Vim, Spell check (status line, "Download dictionaries" on failure), Session and Key bindings (live chord capture with "Press keys... (Esc to cancel)", inline "Already used by X" with Replace/Cancel, "Reset to defaults"). Every change is applied live and saved to `settings.toml` immediately. While capturing, the frame's key events are consumed before shortcut dispatch; while a settings text field has focus only `OpenSettings` fires. Fonts (`src/fonts.rs`): the editor and the vim command bar draw with the egui family `"editor"`, which aliases the bundled Hack font until a system font loads; `FontCatalog` scans the system fonts with fontdb on a background thread the first time the settings window opens, and at startup a configured `font_family` is loaded on its own background thread (a missing family keeps the default font with a status bar warning). Spell suggestions no longer open for stale marks while spell check is off.
- Task 15: performance pass, README and release build. `FED_TRACE_STARTUP=1` prints the time from process start (captured in `main`, passed to `fed::run`) to the end of the first frame; release startup with one small file measures 63-76 ms (5 runs, spell check off and on). `HighlightCache::line_spans` returns cached lines before building a `Highlighter`, compares its `(syntax, theme)` key without allocating, and `span_kind` tests precomputed `comment` / `string` scopes with `Scope::is_prefix_of` instead of formatting every scope (now atom-wise, so `stringy.x` is no longer a string). `Tab::refresh_syntax` looks the syntax up only when assets first load or the buffer path changes, and the syntax name is no longer cloned every frame. `FontCatalog::families` returns a shared `Arc<[(String, bool)]>` instead of copying the list every frame. Font size and tab width drags apply live but save only on drag stop / focus loss or at most every 500 ms (`SaveDebounce`, flushed on exit); other changes still save immediately. Key capture rejects chords without Ctrl/Cmd/Alt unless the key is F1-F20, showing "Shortcut needs a modifier key" and staying in capture. Large files now also turn word wrap off (spec 5.1.2), with the status notice "large file: highlighting, spell check and wrap off". Added `README.md` (build, usage, shortcuts, vim support, settings location, dictionaries, large files, measured startup and memory). `cargo build --release` passes on Linux and `cargo check --target x86_64-pc-windows-gnu` passes; the Windows binary and macOS builds are pending verification on those systems.
- Task 15 fix: links clicked in the Markdown preview now open in the system browser. At the end of each frame `FedApp::open_links` takes egui's `OutputCommand::OpenUrl` commands out of the platform output (so the backend, built without eframe's `links` feature, never sees them) and opens `http`, `https`, `mailto` and `file` URLs (`markdown::is_openable_url`) with `open::that` on a background thread; other URLs are ignored and opener errors appear in the status bar.
- Final review fixes: clicked preview links open only `http`, `https` and `mailto` URLs (`file:` removed, it could launch programs or leak SMB credentials) and the trimmed URL is passed to the opener; ropey is built without `unicode_lines`, so only LF breaks lines (form feed, VT, NEL, U+2028/2029 are plain characters and `dd` no longer deletes past them); the save line ending is the majority one (CRLF vs bare LF, ties to LF) instead of CRLF as soon as one CRLF appears; the preview resolves images of files opened with a relative path against an absolute base directory; `settings.toml` and `session.toml` are written atomically (temp file plus rename); a panic in the dictionary loader thread sets the spell status to `Failed("dictionary loader crashed")` so a retry is offered; `Buffer::save_as` binds the new path only after the write succeeds; the image destination rewrite searches after the `](`, so an identical title or alt text is not rewritten instead.
- Tab bar restyle: tabs are drawn by `draw_tab` (`src/app.rs`) with a flat look, a blue accent line on top of the selected tab, thin separators, and a painted close "x" (shown on the selected or hovered tab; a modified tab shows a dot that turns into the "x" on hover).
- "Preview" button moved to the right of the tab bar, wider (110 px) with slightly rounded corners (`draw_preview_button`); tabs scroll in the remaining space.
- Tab bar fix: tabs stay left-aligned; the scroll area takes the width minus the Preview button, which sits at the right edge.
- Added "Markdown preview" settings section: `preview_font_family` and `preview_font_size` (new `preview` egui font family aliasing the proportional fonts; headings scale from the base size).
- Fixed syntax highlighting of `.ts`/`.tsx` files: syntaxes now come from the `two-face` extra pack instead of syntect's defaults.
- Fix: first view of a tab with a big grammar (TypeScript) froze the UI for ~300 ms in release (~3 s in debug) while syntect lazily compiled the syntax regexes. `HighlightAssets::ensure_warm` now compiles them once per syntax on a background thread by parsing the tab text; the tab shows plain text until it is done and repaints when the colors are ready.
- Debug builds now compile dependencies with `opt-level = 3` (`[profile.dev.package."*"]`), so highlighting and rendering are not ~10x slower under `cargo run`.
- Settings window rewritten as a two-pane layout: section list on the left (Editor, Appearance, Markdown preview, Vim, Spell check, Session, Key bindings), the selected section's settings on the right in a scroll area. Collapsible headers removed; switching away from Key bindings cancels a running key capture or pending conflict.
- Added a hamburger menu at the far right of the tab bar (`src/app/menu.rs`): New tab, Open file, Close file, Save, Save As (with their current shortcuts), About, Quit. Quit goes through the window close request, so unsaved files ask for confirmation. About shows name, version, author, license and clickable GitHub links (opened via `FedApp::open_links`).
